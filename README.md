## 📁 Projects Overview

### 🛒 BUY-CART
A simple e-commerce shopping cart web application built with vanilla JavaScript, HTML, and CSS.

**Features:**
- Product search functionality
- Dynamic cart management
- Responsive design
- Real-time cart count updates

**Technologies:** HTML, CSS, JavaScript

**Location:** `BUY-CART/`

---

### ✋🖱️ HandSync
A camera-driven virtual mouse and gesture control system using computer vision and hand tracking.

**Features:**
- One-finger cursor movement
- Natural pinch-to-click gestures
- Two-finger scrolling
- Dynamic calibration for different hand sizes
- Anti-shake smoothing and click safety

**Technologies:** Python, OpenCV, MediaPipe, PyAutoGUI

**Location:** `HandSync/`

**Requirements:**
- Python 3.11 (recommended)
- Webcam
- MediaPipe 0.10.9
